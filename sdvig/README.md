# СДВИГ / SDVIG

Самостоятельный магазин-концепт для портфолио TRY/HARD. Вымышленная марка, оригинальная айдентика и авторские иллюстрации вещей. Это не настоящий продавец: товары, остатки, скидка и доставка демонстрационные.

Адрес магазина: https://tryhardworking.github.io/sdvig/  
Портфолио: https://tryhardworking.github.io/

## Запуск

Нужен Node.js 22 или новее. Зависимостей npm нет.

```sh
npm run dev
```

Открыть http://localhost:4190/sdvig/. Сервер также показывает соседнее портфолио по /portfolio/. При публикации достаточно статического хостинга с поддержкой ES-модулей; положите папку `sdvig` рядом с файлами портфолио. Сборка и серверный API не нужны.

## Что работает

- Каталог из 12 вещей, поиск, категории, цена, размер, цветовая группа, сортировка и избранное.
- Карточка вещи: цвет, изображения спереди/сзади, размеры, таблица измерений, состав и уход.
- Конструктор трёх образов с индивидуальными размерами и атомарным добавлением комплекта.
- Корзина: отдельные варианты и размеры, количество с учётом демо-остатка, удаление, промокод `SDVIG10` (10%), стоимость доставки.
- Демо-оформление с проверкой полей и локальным подтверждением. Нет платежей, отправки данных, аналитики, cookies, внешних запросов или выдуманных отзывов.
- Корзина и избранное сохраняются в `localStorage`. Контактные данные не сохраняются; после подтверждения поля очищаются. Повреждённое или недоступное хранилище не блокирует магазин.
- Адаптивность, клавиатура, нативные модальные окна, возврат фокуса, режим уменьшенного движения.

## Проверки

```sh
npm test
npm run test:browser
```

Браузерные проверки используют установленный Microsoft Edge / Chromium и отдельный временный профиль, не затрагивая пользовательский. Результаты сохраняются в системную папку OpenCode. Подробный фактический отчёт — `QA-REPORT.md`.

## Ресурсы и лицензии

Все ресурсы лежат локально. Генератор `tools/prepare-assets.mjs` создаёт оригинальные SVG-макеты изделий; фотографии не выдаются за фотографии этих товаров.

- Manrope и Oswald — SIL Open Font License, тексты лицензий в `assets/fonts/`.
- Фотографии для вымышленной кампании — Unsplash, [лицензия](https://unsplash.com/license). [Кампания](https://images.unsplash.com/photo-1539109136881-3be0616acf4b), [студия](https://images.unsplash.com/photo-1551232864-3f0890e580d9). Изображения обработаны в чёрно-белую гамму. Упоминания реальных брендов и утверждения о сотрудничестве отсутствуют.

Для настоящего магазина понадобятся реальные товары/фото, серверная проверка цен и остатков, платёжный провайдер, доставка, юридические документы и защищённая обработка персональных данных. Добавлять секретные ключи в frontend нельзя.

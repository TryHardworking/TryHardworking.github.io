# TRY/HARD — портфолио 2026 (новая версия)

Премиальный сайт-портфолио в фирменной палитре TRY/HARD: тёмный flagship-первый
экран с кинетической типографикой (Manrope + Lora italic, акцент `#c9efa9`),
editorial-сетка кейсов в browser-окнах, тёмный блок NEXUS CRM, hover-invert
подход и аккордеон этапов. Полный motion-слой: интро-занавес, reveal'ы,
параллакс, магнитные кнопки — всё с уважением к `prefers-reduced-motion`
и ручным тумблером «Меньше анимаций».

## Состав

- `index.html` — единственная страница: интро, hero, 4 концепта, кейс NEXUS CRM,
  обо мне, подход THINK/DESIGN/BUILD, этапы работы, контакты.
- `styles.css` — вся дизайн-система (без зависимостей).
- `app.js` — motion-движок (интро, cycler, count-up, параллакс, магнитные кнопки),
  анимированное мобильное меню, активная навигация, авто-год,
  переключение ссылок на локальные пути при запуске на localhost.
- `assets/fonts/` — Manrope (cyrillic/latin) и Lora Italic (woff2).
- `assets/images/` — портреты, превью проектов (webp) и скриншоты NEXUS CRM (jpg).
- `favicon.svg`, `serve.ps1`.

## Запуск локально

Сайт — статика, но NEXUS CRM требует HTTP (ES-модули не работают с `file://`),
поэтому используйте сервер из комплекта:

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

- Сервер слушает `http://localhost:8901/` и обслуживает корневую папку workspace.
- Открыть сайт: **http://localhost:8901/tryhard-portfolio-new/**
- Открыть CRM по ссылке с сайта: кнопка «Открыть NEXUS CRM» → `../nexus-crm/`

- Все 12 изображений загружаются (`naturalWidth > 0`).
- Консоль браузера чистая: 0 ошибок, 0 предупреждений.

**Анимации**

- Reveal-эффекты 27/27, каскадные задержки 9/9, подсветка врезок 3/3, шторки
  интро, счётчики, cycler слов, sheen кнопок, живой фон hero — работают.

- Слово «замечают.» в hero подсвечивается только при наведении на само слово.
- Карточки работ: подъём, рамка, многослойное мягкое свечение, акцентная
  полоса, плавный zoom изображения.

**Исправления v3–v5**

- Удалена служебная лента перед контактами (дублировала ленту в hero).
- Hover-стили перенесены в единый media-блок — фикс «залипания» на мобильных.
- Вертикальные отступы секции контактов — убран визуальный стык с фоном.
- `overflow-x: clip` на секции работ — декоративное свечение карточек больше
  не создаёт горизонтальный скролл на узких экранах.

## Фикс навигации (v6)

- При клике по навигации над целевой секцией оставалась полоса фона
  предыдущей секции — на светлых секциях она выглядела как белая полоса.
- Причина: `scroll-padding-top` был на 20px больше высоты шапки
  (`calc(var(--header-h) + 20px)` при шапке 76px) — этот зазор показывал
  хвост предыдущей секции.
- Фикс: `scroll-padding-top: var(--header-h)` — секция примыкает вплотную
  к нижнему краю шапки, чужой фон не виден.
- Проверено вживую и в headless: все 5 ссылок навигации на 1440×900 и
  390×844 садятся вплотную к шапке, подсветка активного пункта работает,
  горизонтального скролла нет, консоль чистая.
